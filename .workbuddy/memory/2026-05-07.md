- **解决方案**：
  - 运行 `debug_beijing_api.py` 查看 API 返回的所有字段
  - 找到正确的日期字段名：`createDateTime`, `publishTime`, `executiondate`, `startdate`
  - 更新 `beijing_land_connector.py` 中的 `date = pick(row, [...])`
  - 将 `beijing_land_connector.py` 和 `debug_beijing_api.py` 从 `requests` 改为使用标准库 `urllib`
