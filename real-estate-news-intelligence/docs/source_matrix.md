# 房地产财经新闻情报系统：信息来源矩阵

## 一、政策信息模块

### 中央部委与监管机构

| 类型 | 信息源 | 用途 |
|---|---|---|
| 土地与规划 | 自然资源部 | 土地政策、规划政策、用地指标、土地储备 |
| 房地产与城市更新 | 住建部 | 房地产政策、保障房、城市更新、保交楼 |
| 金融监管 | 央行 | 房地产金融、信贷、货币政策 |
| 金融监管 | 金融监管总局 | 房地产融资、银行贷款、风险监管 |
| 资本市场 | 证监会 | REITs、房企融资、资本市场政策 |
| 财政资金 | 财政部 | 专项债、财政支持政策 |
| 宏观政策 | 国务院、新华社 | 宏观经济与房地产定调 |

## 三、土地交易模块

| 来源 | 用途 |
|---|---|
| 中国土地市场网 | 全国土地公告与成交 |
| 地方自然资源部门 | 土地出让公告与成交信息 |
| 公共资源交易中心 | 招拍挂结果 |
| 克而瑞 | 土地市场统计 |
| 中指研究院 | 城市土地市场分析 |

重点监测指标：

- 土地成交金额
- 土地成交面积
- 溢价率
- 底价成交率
- 流拍率
- 城投拿地占比
- 民企拿地占比
- 央国企拿地变化
