# 房地产财经新闻情报与项目库系统

本项目用于构建一个面向财经记者的房地产新闻情报系统，目标是把分散的信息源、数据、政策、公告、土地交易、市场数据、采访素材和稿件生产流程整合为一个可持续积累的本地项目库。

## 一、系统目标

系统围绕“采集—判断—生产—核验”四个环节运行：

1. 自动或半自动采集权威信息源，包括上市公司公告、政策文件、土地交易、房地产交易数据、第三方机构报告、券商研报、会议论坛观点等。
2. 对信息进行结构化入库，保留原始出处、发布时间、数据口径和原文链接。
3. 对新增信息进行分析判断，识别政策变化、市场异动、企业风险、土地市场变化和潜在新闻选题。
4. 围绕选题生成素材包、采访方案、数据表、写作提纲和稿件初稿。
5. 对成稿进行事实核验、数据口径检查、引用来源核对和编辑精校。
6. 形成长期可积累的个人财经新闻知识库。

## 三、信息源覆盖范围

1. 上市公司公告：港交所披露易、上交所、深交所、北交所、公司官网、Wind、Choice、同花顺等。
2. 政策信息：自然资源部、住建部、证监会、央行、金融监管总局、财政部、发改委、地方政府及相关部门。
3. 土地交易：地方自然资源部门、公共资源交易中心、中国土地市场网、克而瑞、中指研究院等。
4. 房地产交易数据：地方住建部门、房管局、房地产交易中心、克而瑞、中指、贝壳研究院、国家统计局等。
5. 观点与判断：中央会议、部委发布会、券商研报、评级机构报告、行业论坛、企业业绩会、专家访谈等。
6. 房企资料：上市公司公告、业绩会材料、公司官网、债券募集说明书、评级报告、销售榜单等。

## 四、系统运行原则

1. 权威来源优先：政府部门、交易所、上市公司公告和官方统计优先于二手转述。
2. 原文留痕：所有核心事实必须保留原始链接、原文文本、抓取时间和文件哈希。
3. 数据口径统一：销售额、权益销售额、合同销售额；土地面积、建筑面积、计容建面；同比、环比等口径必须区分。
4. 判断与事实分离：事实来自权威材料，判断来自采访、研报、论坛、专家观点，稿件中必须区分。
5. 可追溯：每个选题、素材、稿件和事实核验项均应能追溯到原始资料。

## 五、建议第一阶段建设内容

第一阶段先建设最小可运行系统，重点覆盖三类信息：

1. 上市房企公告；
2. 中央及重点城市房地产政策；
3. 土地成交与城投拿地。

第一阶段目标产出：

1. 每日房地产信息摘要；
2. 政策变动提醒；
3. 房企公告异动提醒；
4. 土地市场异动提醒；
5. 候选选题卡片；
6. 选题素材包；
7. 采访方案；
8. 稿件初稿与事实核验清单。
