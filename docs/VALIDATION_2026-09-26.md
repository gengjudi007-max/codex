# 程序验证与编辑规则修正

## 验证结果

- 基线：90项 unittest 测试，4项断言失败、3项运行错误。
- 修正后：93项 unittest 测试全部通过。
- `pip install -e . --no-build-isolation` 安装成功。
- `python -m codex.main` 执行成功。
- 启动本地 HTTP 服务，验证首页、`/health`、选题和稿件编辑 POST 接口通过。
- `git diff --check` 通过。
- 当前环境未安装 pytest，未运行 pytest 测试；以上结果来自项目 README 指定的 unittest 测试集。

## 修正内容

恢复文档解析后的监测和选题处理、终端数据导入后的城市对比、资料检索的顶层结果字段及资料库统计路由。保留检索的嵌套字段，兼容现有调用。总流程仅对显式 draft 字段执行稿件体检，避免把线索当作稿件。补充单句企业宣传口号的高风险识别。关闭队列日志文件，消除资源未释放警告。

编辑遵循保留事实、采访原意、数字、专名和判断强度的原则。停止用近义词机械替换宣传及确定性表达；这类问题保留给人工核验。保留直接引语和段落，仅对有明确主体的句首自称进行有限转换。删除导语自动附加的行业泛化结论；来源核验说明独立存放。数字来源检查改为逐句提示，避免其他句子的“公告”掩盖未注明出处的数据。导语超过500字才提示检查冗余，不再以120字机械判断过长。

新增回归测试覆盖引语、完整企业名称、子公司、数字、段落及缺少主体时的保留行为。两个原测试改为检验事实和判断强度保留，不再要求程序擅自弱化原文或向导语添加套话。

## 验证边界

这是本地运行与规则层回归验证，未逐站验证交易所、土地平台及商业终端的联网抓取、凭据和数据时效。未验证 Windows/macOS 桌面打包。系统仍以规则和报道框架为主，测试通过不代表生成文本已经达到可发布标准；事实、因果和信源需要记者核验。
